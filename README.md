# TrailReady 微信小程序（测试版）

在「准备」输入目的地与出发日期，选定地点后，AI 会参考个人装备和以往徒步经历，推荐天数、每日路线及装备清单。确认采用后会创建一趟新行程，并把缺少的物品加入待办。也可以手工安排行程。装备、经历和已保存的行前清单都保存在微信本地。

**[开发交接文档](docs/MINIPROGRAM_HANDOFF.md)** 包含运行步骤、页面入口、数据存储、测试命令，以及在线服务和真机验证进度。

使用微信开发者工具导入 [miniprogram](miniprogram/) 目录。初次运行先安装 npm 依赖，并在开发者工具中构建 npm。[小程序说明](miniprogram/README.md)
